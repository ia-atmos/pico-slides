# Resources

- `DejaVuSans.ttf`: the font DejaVu Sans, from the DejaVu Fonts project
  (<https://dejavu-fonts.github.io/>), a copy of the file in
  `ia-atmos/env-pico` (`c/res/`). It is free to use and to redistribute,
  under the license of the project
  (<https://dejavu-fonts.github.io/License.html>), based on Bitstream
  Vera. It is here so that the tests and the examples have a font with
  accents, which the built-in font of pico does not have.
- `DejaVuSansMono.ttf`: DejaVu Sans Mono, of the same project and
  license, copied from the package `fonts-dejavu` of Debian. It is the
  font of code in the tests and the examples.
